Display

Applies to the capture card itself, so it affects every connected client. Higher resolutions and frame rates need more bandwidth: 1080p30 MJPEG is roughly 50 Mbps on the wire.

Enter or exit browser fullscreen mode.

Audio

Play the HDMI audio captured by the card.

The stream is downsampled on the Pi before it is sent, so a lower quality costs less bandwidth. Standard is 24kHz stereo.

Boost the remote audio when the source is quiet.

Keyboard & Mouse

Show your own cursor on top of the remote screen.

Reverse the scroll direction sent to the remote machine.

Sends pointer deltas instead of absolute positions. Needed for games and for remote desktops that do their own pointer acceleration. Click the screen to capture the pointer, press Esc to release it.

Multiplier applied to pointer deltas in relative mode.

Nudges the remote pointer after 30 seconds of inactivity so the machine does not go to sleep. This runs on the Pi, so it keeps working after you close this tab.

Ask before typing clipboard contents into the remote machine.

Hotkeys

Build a key combination one key at a time and send it in a single HID report. This is how combos your own OS swallows, like Ctrl + Alt + Del, reach the remote machine.

Hold this key to start stacking, tap it again to send.

How long the toggle key must be held before stacking starts. Set to 0 to enter stacking on a plain tap.

Device

The device nodes the server picked at startup. To override them, restart the server with -video, -audio or -tty.

Loading…

Soft resets the CH9329 and releases every modifier key. Use this if the remote machine thinks Ctrl or Shift is stuck down.

Everything on this panel is stored in this browser only; the server keeps no per-user configuration.

About

DezKVM-Go IP KVM serves the HDMI capture card and the CH9329 HID bridge over the network, so any browser on the LAN can see and control the remote machine. Unlike the local USB mode, the browser never touches the hardware directly.

This is a prototype for internal use. Do not expose it to the internet.
